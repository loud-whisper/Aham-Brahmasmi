# My Brain workspace

This folder belongs to you. It is separate from the public Aham Brahmasmi framework.

Keep personal memory, project state, history, tasks and lessons here. Do not move private material into the public framework repository.

The framework may read or update this workspace only through the rules you choose and the capabilities available in the current runtime.

Keep `INDEX.json` aligned with top-level context files and project folders. Each
project folder needs a `PROJECT.md` record. The index also sets the startup source
byte budget. Run `aham.py check --workspace WORKSPACE` after changes. See
`docs/DRIFT_CHECKS.md` in the framework for the format and migration procedure.
